4 · Schedule

Tap the days games will be played, then set each day’s start time, number of games, and minutes between games. Add a field to run games on more than one surface — games then run in concurrent waves so the day finishes sooner, and each day can be limited to the fields it actually uses (e.g. championship day on one field). Games fill the days in bracket order — early rounds first.
